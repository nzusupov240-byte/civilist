# Цивилист — сайт юридической компании

Современный премиальный сайт-визитка для юридической компании «Цивилист»
(Бишкек, Кыргызстан). Построен на **Next.js 16 (App Router) + TypeScript +
Tailwind CSS 4**.

## Быстрый старт

Требуется установленный **Node.js 18+**.

```bash
npm install       # установка зависимостей
npm run dev       # запуск в режиме разработки → http://localhost:3000
npm run build     # production-сборка
npm run start     # запуск собранного проекта
```

## Где менять контент и контакты

Все тексты и контактные данные собраны в **одном файле**:

```
src/config/site.ts
```

Контактные данные (телефон, WhatsApp, email, адрес) находятся в объекте
`contacts`. Пустые поля (`""`) автоматически скрываются на сайте — заполните
их значениями, и соответствующие блоки появятся.

```ts
contacts: {
  phone: "+996 XXX XXX XXX",
  whatsapp: "+996 XXX XXX XXX",     // или ссылка https://wa.me/996XXXXXXXXX
  email: "info@civilist.kg",
  address: "г. Бишкек, ул. ..., офис ...",
}
```

## Форма заявки

Логика отправки разделена на две части:

- **Клиент:** `src/lib/submitApplication.ts` — единственная функция
  `submitApplication()`, которую вызывает форма. Менять её не нужно.
- **Сервер:** `src/app/api/application/route.ts` — обработчик заявки.
  Это единственное место для подключения реального канала.

По умолчанию заявка просто логируется на сервере. Чтобы подключить
**Telegram / webhook / email / CRM**, раскомментируйте нужный блок в
`route.ts` и добавьте переменные окружения (см. `.env.local.example`).

Поведение формы: валидация обязательных полей (имя, телефон), состояние
загрузки, сообщение об успехе и обработка ошибки — без перезагрузки страницы.

## Структура компонентов

```
src/
├─ app/
│  ├─ layout.tsx          # шрифты, SEO, Open Graph
│  ├─ page.tsx            # сборка всех секций + микроразметка
│  ├─ globals.css         # дизайн-токены, типографика, анимации
│  ├─ icon.svg            # favicon
│  └─ api/application/    # серверный обработчик заявки
├─ components/
│  ├─ Header.tsx          # шапка + мобильное меню
│  ├─ Hero.tsx            # первый экран
│  ├─ About.tsx           # о компании
│  ├─ Services.tsx        # услуги
│  ├─ Advantages.tsx      # почему мы
│  ├─ Process.tsx         # как мы работаем
│  ├─ CTA.tsx             # промежуточный призыв
│  ├─ ApplicationForm.tsx # форма заявки
│  ├─ Contacts.tsx        # контакты
│  ├─ Footer.tsx          # подвал
│  ├─ MobileCTA.tsx       # фиксированная кнопка на телефонах
│  └─ ui/                 # переиспользуемые элементы (кнопки, контейнер и т.д.)
├─ config/site.ts         # ВЕСЬ контент и контакты
└─ lib/submitApplication.ts
```

## Деплой

Проект готов к развёртыванию на **Vercel** (или любой платформе с поддержкой
Next.js): подключите репозиторий — сборка и API-маршрут заработают
автоматически. Переменные окружения задаются в настройках проекта.
